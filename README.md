# MV LEDs Gestão

Estoque, vendas, agenda e pedidos da MV LEDs, direto no navegador do celular.

- Estoque com aviso de peças acabando
- Vendas, entradas e perdas que atualizam o estoque sozinhas
- Agenda com calendário, alarme no celular e Google Agenda
- Pedido de reposição, orçamento, comprovante e resumo pelo WhatsApp
- Cópia de segurança em arquivo

Os dados ficam salvos no próprio navegador (localStorage).

Feito por Synex Sistemas.
